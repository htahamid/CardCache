# CardCache

Build more decks. Buy fewer cards.

## About

CardCache is an inventory-aware Magic: The Gathering
deckbuilding application.

It helps players discover useful cards in their existing
collections and complete unfinished Commander decks
while reducing unnecessary purchases.

## Features

- Import a card collection
- Import an unfinished Commander deck
- Find legal cards from your collection
- Recommend cards based on deck strategy
- Estimate deck completion costs

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Scryfall API
